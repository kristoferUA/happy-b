# Листівка для Юлії Матвійчук

Сайт працює локально без збірки, встановлення пакетів і сторонніх сервісів.

## Відкрити

Відкрий `dist/index.html` у браузері подвійним натисканням. Усі картинки й скрипти локальні, інтернет не потрібен.

## Додати побажання

Відредагуй `dist/wishes.js`. Кожен рядок у `paragraphs` стане окремим абзацом. Наприклад:

```js
window.birthdayLetter = {
  paragraphs: [
    "Тут напиши перший абзац побажання.",
    "Тут напиши другий абзац."
  ],
  signature: "Твій підпис"
};
```

Збережи файл і онови сторінку. Поки `paragraphs` порожній, конверт відкриває чистий лист із декоративними лініями. Текст вставляється без виконання HTML.

## Що є на сторінці

- Іменне привітання й акварельні троянди.
- Анімований конверт, лист із твоїм текстом і закриття клавішею Escape.
- Торт зі свічкою: натисни, щоб задмухнути її та запустити конфеті; свічку можна запалити знову.
- М'яка поява елементів, мерехтіння й плавний рух ілюстрацій.
- Верхня кнопка «Відкрити конверт» прокручує до секції з листом і тортом; лист відкривається натисканням на сам конверт.
- Мобільна версія та керування з клавіатури. Враховано системне налаштування зменшення руху.

Онлайн сайт не опубліковано. Усі ілюстрації створено спеціально для цієї сторінки: акварельний букет троянд, святковий конверт і бордово-кремовий торт у двох станах свічки. Асети з попередніх привітань не використовуються.
