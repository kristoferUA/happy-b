# З днем народження, Олю!

Локальна односторінкова дружня листівка для **Олі Козел** у стилі святкового пікніка: блакитна картата скатертина, жовта паперова листівка, наліпки, акварельні польові квіти, конверт, торт зі свічкою та конфеті. Без романтичних фраз і сердечок.

## Відкрити

Відкрий `dist/index.html` у браузері. Сайт працює без інтернету, встановлення пакетів і збірки.

Для локального сервера з Node.js виконай `npm run dev` у цій папці та відкрий **http://127.0.0.1:4173**. Зупинка сервера — Ctrl+C. За потреби порт можна змінити через змінну середовища `PORT`.

## Додати власні побажання

Відкрий **`dist/wishes.js`** та заповни масив `paragraphs`. Кожен елемент — окремий абзац. Поле `signature` — необов’язковий підпис.

```js
window.birthdayLetter = {
  paragraphs: [
    "Твій перший абзац.",
    "Твій другий абзац."
  ],
  signature: "Твій підпис"
};
```

Збережи файл та онови сторінку. Поки масив порожній, у конверті буде чистий розлінований лист. Текст вставляється без HTML, тому лапки та розмітка не стають елементами сторінки. Щоб додати подвійні лапки всередині рядка, пиши `\"` або використовуй одинарні лапки навколо рядка.

## Що можна натискати

- Конверт і «Відкрити конверт» відкривають лист. Його можна закрити хрестиком, клавішею Escape або натисканням поза листом.
- Торт і «Задмухнути свічку» гасять полум’я й запускають конфеті.
- «Запалити ще раз» повертає свічку.
- «Конфеті!» та «Ще один залп конфеті» запускають новий залп.

Є адаптація під телефон, керування клавіатурою і підтримка системного налаштування зменшеного руху. Звуку та доступу до мікрофона немає.

Ілюстрації створені вбудованим ImageGen; промпти збережені в `asset-prompts.json`. Сайт не публікувався.
